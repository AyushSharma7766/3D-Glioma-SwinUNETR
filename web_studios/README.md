# Standalone Zero-Install HTML5 Neurosurgical Studios

This directory contains standalone, self-contained interactive 3D WebGL neurosurgical studios generated by `make_studio.py`.

## Zero-Dependency Architecture
Each `.html` file is a complete, self-contained web application (6–7 MB) with:
* The 3D patient MRI scan (base64 encoded NIfTI)
* The 3D predicted tumor segmentation mask (base64 encoded NIfTI)
* The co-registered Marching Cubes solid cortical surface mesh (base64 encoded Wavefront OBJ)
* An embedded NiiVue WebGL medical imaging engine

## Key Features

1. **Zero Installation:** Runs immediately on any modern web browser (Chrome, Edge, Firefox, Safari) on laptops, hospital workstations, or mobile tablets without installing Python, PyTorch, CUDA, Docker, or external drivers.
2. **Air-Gapped & Offline Capable:** Does not transmit patient scans over the network; fully compliant with hospital data privacy and HIPAA standards.
3. **Synchronized Dual Viewports:**
   * **Top View:** 2D Orthogonal Multi-Planar Reconstruction (Axial, Coronal, Sagittal) with crosshairs and 3D volume rendering.
   * **Bottom View:** Co-registered solid cortical surface mesh.
4. **Live Virtual Trepanation (SyncMesh):** Dynamic clipping plane slider allows neurosurgeons to virtually cut through the skull and cerebral cortex at arbitrary depths and angles to examine how deep the tumor is buried below the cortical surface.
